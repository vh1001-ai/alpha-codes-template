# Alpha Codes Elementor & Landing Kit

این بسته شامل تمامی صفحات، قالب‌ها، لندینگ‌ها و فایل‌های JSON آماده برای ایمپورت در **Elementor** (قالب ساز وردپرس) است.

### نحوه ایمپورت در وردپرس و المنتور:
1. وارد پنل مدیریت وردپرس خود شوید.
2. به بخش **المنتور (Elementor) > ابزارها (Tools) > درون‌ریزی/برون‌ریزی کیت (Import/Export)** بروید.
3. فایل  (یا فایل‌های قالب کامل موجود در این ریپازیتوری) را بارگذاری کنید.
4. تمامی صفحات اصلی، لندینگ‌ها، فروشگاه و منوها به صورت المان‌های زنده المنتوری بارگذاری خواهند شد.
